# REZONIQ organization profile

This repository publishes the [REZONIQ](https://github.com/REZONIQ) organization profile from
[profile/README.md](profile/README.md). It has no application or deployment.

Run `just check` with the NDDev documentation tools installed to check the Markdown and justfile.
Product research and decisions live in the private `REZONIQ/rezoniq` repository.

The organization avatar is [the REZONIQ orbital R](profile/assets/rezoniq-avatar.png).
Use the [JPEG copy](profile/assets/rezoniq-avatar.jpg) for GitHub's avatar upload limit.
